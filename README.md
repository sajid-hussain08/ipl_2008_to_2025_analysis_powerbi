# 🏏 IPL Analysis (2008 - 2025) | Power BI Dashboard
## 📊 Project Overview

This project presents a comprehensive data analysis of **IPL seasons from 2008 to 2025,**  using Power BI to build a fully interactive dashboard.
It uncovers detailed insights into team performance, player statistics, match outcomes, and season trends — all powered by advanced DAX measures, data modeling, and visual storytelling.

## 📊 Project Highlights

### ⚙️ Tools & Technologies
- **Power BI** — Data Visualization & Dashboard Design  
- **DAX (Data Analysis Expressions)** — Custom measures for insights  
- **Power Query** — Data cleaning & transformation

- ### 📈 Key Features
✅ Season-wise filter (2008–2025)  
✅ Team-wise comparison (Champion & Runner-Up)  
✅ Orange Cap and Purple Cap analysis  
✅ Top 4’s and 6’s players visualization  
✅ Points Table (auto-calculated using DAX)  
✅ Interactive and IPL-themed dashboard UI

## 📈 Key Insights & KPIs

🏆 Season Champions & Runner-Up Teams
💥 Total 6s, 4s, Matches, and Venues per Season

- 🟠 Orange Cap (Most Runs)
- 🟣 Purple Cap (Most Wickets)
- 🔝 Top 4s and 6s Players
- 📊 Dynamic Points Table (Auto-calculated using DAX)
- 📅 Interactive Season Selection (2008–2025)
